# Conceitos: a regra se espalha pelo produto

<CaseNavigation caseId="order-boundaries" current="concepts" />

Este mapa conecta os conceitos ao mesmo problema. Ana é uma operadora fictícia de uma corretora. O provedor envia uma autorização como AUTHORISED e o produto espera accepted. Se cada tela interpretar o contrato sozinha, a mesma ordem pode parecer recusada em um lugar e aceita em outro. O exemplo concentra a tradução e deixa a regra financeira dentro da operação.

Comece pela [jornada](/jornadas/order-boundaries/), execute o [tutorial](/jornadas/order-boundaries/#tutorial) e use a [referência](/jornadas/order-boundaries/#reference) para consultar parâmetros. Para resolver sua própria tarefa, siga o [guia](/jornadas/order-boundaries/#guide).

Cada entrada informa se você observa um mecanismo local ou se compara um princípio que uma implementação completa também precisaria atender. O segundo caso conserva a distância entre um modelo finito e um protocolo ou produto real.
