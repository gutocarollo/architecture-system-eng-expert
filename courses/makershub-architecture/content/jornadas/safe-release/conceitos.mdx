# Conceitos: a versão nova chega a quem ainda usa a antiga

<CaseNavigation caseId="safe-release" current="concepts" />

Este mapa conecta os conceitos ao mesmo problema. A corretora hipotética troca amount por amount_cents. A interface antiga ainda lê amount. Remover o campo antigo na primeira implantação faz a consulta retornar vazio. A prática conserva os dois campos durante a transição e expõe a versão nova a cinco das cem requisições fictícias.

Comece pela [jornada](/jornadas/safe-release/), execute o [tutorial](/jornadas/safe-release/#tutorial) e use a [referência](/jornadas/safe-release/#reference) para consultar parâmetros. Para resolver sua própria tarefa, siga o [guia](/jornadas/safe-release/#guide).

Cada entrada informa se você observa um mecanismo local ou se compara um princípio que uma implementação completa também precisaria atender. O segundo caso conserva a distância entre um modelo finito e um protocolo ou produto real.

## A/B Deployment

O desenho expõe grupos a variantes para comparar uma hipótese de comportamento ou resultado.

No caso desta família, faça a seguinte observação: Distribua quatro usuários entre A e B; confira que os dois grupos recebem respostas visíveis diferentes e mantêm sua associação ao usuário.

```sh
python3 labs/architecture/financial.py safe-release --probe ab-cohorts
```

O código desta observação está em `labs/architecture/financial.py`. O identificador do probe é `ab-cohorts`.

Confira os valores do contrato antes e depois, e não apenas se as duas saídas são diferentes:

```json
{
  "before": {
    "visible_cohorts": [
      "A"
    ],
    "fees": [
      1,
      1,
      1,
      1
    ]
  },
  "after": {
    "visible_cohorts": [
      "A",
      "B"
    ],
    "fees": [
      1,
      2,
      1,
      2
    ],
    "assignment_stable": true
  }
}
```

O vínculo é uma comparação executável de princípio. O probe exercita um requisito ou um contraexemplo relacionado a A/B Deployment; não implementa o padrão completo. Esta é uma simulação de contratos e rotas em memória. Não houve deploy, Kubernetes, GitOps ou Terraform. Desviar tráfego não desfaz dados incompatíveis já gravados.
