# Conceitos: um leitor cancela a busca

<CaseNavigation caseId="single-flight-cancel" current="concepts" />

Este mapa conecta os conceitos ao mesmo problema. Um assessor deixa de aguardar a lista de chamadas enquanto outros quatro continuam esperando. O commit de FBI-2331 relata que cancelar um participante cancelava a tarefa compartilhada e derrubava os cinco leitores. A reprodução usa cinco participantes fictícios e a mesma classe das duas versões.

Comece pela [jornada](/jornadas/single-flight-cancel/), execute o [tutorial](/jornadas/single-flight-cancel/#tutorial) e use a [referência](/jornadas/single-flight-cancel/#reference) para consultar parâmetros. Para resolver sua própria tarefa, siga o [guia](/jornadas/single-flight-cancel/#guide).

Cada entrada informa se você observa um mecanismo local ou se compara um princípio que uma implementação completa também precisaria atender. O segundo caso conserva a distância entre um modelo finito e um protocolo ou produto real.
