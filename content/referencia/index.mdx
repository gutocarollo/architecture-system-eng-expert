# Referência de arquitetura

Esta parte descreve os termos e os contratos usados na trilha. Cada conceito conserva uma ligação com o catálogo original, com o capítulo que o explica e com as fontes que sustentam os exemplos.

- Consulte o [catálogo completo](/referencia/catalogo) para encontrar os conceitos dos 18 grupos.
- Consulte os [40 padrões prioritários](/referencia/prioritarios) para escolher o próximo estudo e comparar implementações.
- Consulte os [recibos dos exemplos](/referencia/evidencias) para conferir ambiente, horário, consulta, resultado e limite.
- Consulte as [skills e os projetos de referência](/referencia/skills-e-projetos) para distinguir orientação para agentes, biblioteca base e aplicação que demonstra o mecanismo.

Uma configuração medida pertence ao ambiente informado. Um código lido pertence ao SHA informado. Uma referência OSS demonstra o mecanismo indicado; a classificação como aplicação didática ou produto faz parte da descrição.
