## Finite State Machine

O identificador canônico é `finite-state-machine`. **A revisão independente aceitou este recorte delimitado.** O mecanismo e os limites abaixo foram conferidos; as observações da revisão continuam nos recibos vinculados ao item.

Uma operação Nexus nasce no estado UNSPECIFIED. O comando de agendamento aplica uma transição para SCHEDULED. Se a chamada falha de forma recuperável, o executor muda o controle para BACKING_OFF; o timer de retry pode devolvê-lo a SCHEDULED. Uma resposta assíncrona muda o controle para STARTED, e um evento de conclusão permite SUCCEEDED. Cada transição declara suas origens aceitas. A base testa o estado atual e devolve ErrInvalidTransition quando a origem não está na lista.

A base genérica aceita S comparable e, sozinha, não exige um conjunto finito. O enum Nexus e suas transições fornecem esse recorte. Não se deduz GoF State desse enum. Também não se afirma atomicidade de persistência a partir de Apply: a função troca o estado antes de chamar o callback, que pode retornar erro.

A decisão pública que sustenta esta leitura está na [fonte do responsável pelo produto](https://docs.temporal.io/nexus/operations). Contexto primário de suporte.
